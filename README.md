# Keely Boland's Portfolio

Personal design portfolio of Keely Boland, graphic designer based in Brisbane.

- Plain HTML, CSS and JavaScript, so there's no build step.
- Open `index.html` in a browser, or host it with GitHub Pages.

## Hosting on GitHub Pages
1. Upload everything in this folder to the root of a GitHub repository, including the `assets` folder.
2. In the repository, go to **Settings → Pages**.
3. Set the source to **Deploy from a branch**, then choose `main` and `/ (root)`.
4. The site goes live at `https://<your-username>.github.io/<repo-name>/`.
